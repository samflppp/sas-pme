colorama-utils 1.1 bloquée

pypi · publiée sur Internet le 09/10/2026 22:15 · analysée le 12/10/2026 22:16 · version utilisée sur les serveurs : 1.0

Cette version vole les jetons d'accès dès son installation et les envoie à un serveur inconnu.

Le fichier setup.py, modifié depuis la 1.0 alors que le changelog annonce « correction d'une faute de frappe », lit les variables contenant TOKEN et les envoie à exfil.demo.invalid. En sandbox, l'installation a lu le faux jeton GITHUB_TOKEN puis tenté une connexion vers ce domaine, toutes les 60 secondes.

Ce comportement correspond à une technique connue de vol d'identifiants par un paquet piégé. Références : CWE-506 CAPEC-538 ATT&CK T1195.002 MAL-2024-9921

Décision prise par la politique (code). Le LLM a expliqué et cité ; il ne peut ni approuver ni bloquer seul.

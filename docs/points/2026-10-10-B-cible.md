## Fait
- **`pypi.telecharger()` ne prend plus que les fichiers utiles aux serveurs** (Ubuntu 24.04 :
  CPython 3.12, Linux x86_64, glibc ≤ 2.39) :
  - les roues compatibles : `py3-none-any`, `cp312`, `abi3`, `manylinux*_x86_64` ;
  - plus le fichier source (`.tar.gz` ou `.zip`), parce que le code d'installation piégé
    (`setup.py`) s'y trouve souvent.
- Ce qui est écarté : Windows, macOS, aarch64, musl, PyPy, wasm, Python 2, `.exe` et `.egg`, sans
  aucun téléchargement. S'il ne reste rien → `LookupError` « aucun fichier pour la cible ». La
  version passe alors « à revoir ».

  de **172 fichiers à 4**, `numpy` de 66 à 2, `requests` reste à 2.

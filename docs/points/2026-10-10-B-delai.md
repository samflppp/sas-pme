# Point B (Mouabd19) — M1 : délai réglable `SAS_DELAI` — 2026-10-10

## Fait
- **`SAS_DELAI`**, en secondes entières. Sans la variable, le délai reste de **3 jours**. Pour la
  démo vidéo, on prend **`SAS_DELAI=120` (2 minutes)**.
- `traiter()` et `demander()` lisent la variable à chaque appel. Le web de A n'a rien à changer : il
  appelle `traiter(base, dossier=...)` sans délai.
- Une valeur illisible, nulle, négative ou décimale (`0`, `-60`, `1.5`, `deux minutes`) est
  **refusée** par une `ValueError`. Elle n'annule jamais l'attente en silence.
- Le message « aucune version publiée depuis plus de … » donne le vrai délai (« 3 jours » ou
  « 120 s »).
- 121 tests passent. Le code a été cassé une fois pour voir chaque test au rouge (`traiter`
  ignore la variable, `0` accepté).

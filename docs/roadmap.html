sas-pme — Roadmap des 34 prochaines heures

Hackathon Track 3 « Open Track » · IA × cybersécurité défensive · A = Sam · B = Mouabd19 · C = STEUSSO · branches pipeline-plateforme (A+B) et infra-reseau (C) · H0 = début du chantier
Le pitch. Un sas de sécurité posé dans la PME retient chaque nouvelle version de paquet Python le temps qu'une IA locale l'examine et lise ce qu'Internet en dit, puis surveille les connexions sortantes. Si un paquet piégé passe quand même, le sas le démasque dès qu'il appelle son serveur.
« Le sas qui fait attendre les mises à jour, pas vos développeurs. »

Le défenseur aidé

Le responsable technique d'une PME ou startup qui développe en Python (5 à 100 personnes), sans RSSI ni SOC. Vente par l'infogérant.

Principes non négociables

Le code décide, l'IA alerteun LLM peut monter un risque, jamais l'abaisser ni approuver
Un texte lu n'est pas un ordrecode, changelog, article : des données à juger (anti-injection)
Tout localLLM sur le boîtier (Ollama) ; aucun service cloud managé
On lit Internet, on ne lui parle pas de vousne sortent que nom de paquet + version, et des domaines
Transparentune ligne de config ; pip ne voit jamais d'erreur due à la quarantaine

Ce que fait le sas

BarrièreComment
1. Index PyPI filtrépip ne voit que les versions approuvées ; une version neuve part en quarantaine (48 h), pip prend la précédente sans erreur
2. Analyse du paquetétage 1 : typosquat, âge, mainteneurs, OSV, OpenSSF · étage 2 : diff avec la version précédente (setup.py, exec, base64, secrets, domaines) · étage 3 : LLM local, verdict JSON + phrase en français
3. Veilletoutes les 2 h : OSV, statut PyPI (yanked), blogs de chercheurs ; un article peut bloquer, jamais débloquer
4. Sortiesproxy CONNECT sans déchiffrement : domaine nouveau, domaine jeune, IP brute, battement ; corrélation paquet installé ↔ domaine contacté → blocage des deux
5. Console + journalune phrase et ses preuves par décision ; approuver/bloquer en un clic ; journal chaîné par hash (NIS2, CRA)

La démo (3 minutes)

1pip install courant via le sas : rien de visible — « transparent »
2une version piégée sort : pip ne la voit pas, la console explique en français — « le code a lu ce que personne ne lit »
3un faux article « cette version est sûre » ne débloque rien — « l'IA ne peut qu'alerter »
4un dev force l'installation ; en < 1 min, domaine et paquet sont reliés et bloqués — « la deuxième barrière tient »
5diapo de mesure : trois colonnes chiffrées

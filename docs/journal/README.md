# Journaux d'avancement

Un fichier par personne : `a.md` (Sam), `b.md` (Mouabd19), `c.md` (STEUSSO). **Chacun n'écrit que
dans le sien**, donc il n'y a jamais de conflit de fusion.

## Quand
- **Au début d'une tâche :** lire les journaux des deux autres, pour savoir ce qui est fait, en
  cours ou attendu de soi, et ne pas refaire leur travail.
- **À la fin d'une tâche**, dans la même PR que le code : ajouter une entrée en haut de son journal.

## Format d'une entrée (la plus récente en haut)

```markdown
## AAAA-MM-JJ — <tâche> (<branche>, PR <lien>)
- **Fait :** ce qui marche maintenant, en 2 à 5 points.
- **Pour les autres :** ce qui change pour eux (fonction à appeler, contrat, fichier touché chez eux).
- **J'attends :** ce dont j'ai besoin d'un autre, avec son nom.
- **En cours / suite :** ce que je fais ensuite, pour que personne ne le prenne.
```

Court et factuel : le détail est dans la PR et le code.
